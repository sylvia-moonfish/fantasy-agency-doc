# 구직 심사

**구직 심사**는 오전 업무의 핵심으로, 구직 신청을 하러 온 NPC의 서류를 검사하고 신청을 접수할 수 있는지 판단하는 게임플레이이다. 판타지 세계를 배경으로 하지만, 올바른 양식과 증빙서류를 요구하고 제출 내용을 대조하는 **관공서식 서류 검사**로 구성된다.

심사를 통과한 NPC는 그날의 [가용 인력](인력%20배정과%20마을%20발전.md#인력-배정)이 된다.

## 용어

| 용어 | 뜻 |
| --- | --- |
| 구직 신청 | NPC가 인력 사무소에 와서 일자리를 신청하는 행위 |
| 구직 심사 | 플레이어가 구직 신청의 서류를 검사하고 접수 여부를 정하는 업무 |
| 구직 자격 | 구직자가 지닌 자격 속성. 심사의 기본 난이도를 정한다 |

## 구직 자격에 따른 기본 난이도

구직 심사 퍼즐의 기본 난이도는 구직자의 **구직 자격**에 따라 나뉜다.

| 구직 자격 | 해당 구직자 |
| --- | --- |
| 조사단 자격 | 엠브릴 조사단의 일원으로 파견된 구직자. 노에라에서 일할 자격을 갖춘 채로 파견되므로 심사할 서류의 종류가 가장 적고 기본 난이도가 가장 낮다. |
| 필로니아 시민 | 필로니아 시민인 구직자. 소속과 발령에 따라 [세부 조건](#필로니아-시민의-세부-조건)으로 나뉜다. |
| 필로니아 특수 노동자 자격 | 필로니아의 특정 공회의 초청이나 구인으로 해외에서 일하러 온 전문 인력. 필로니아 시민권은 없지만 공회정이 발행한 특수 노동자 자격을 갖고 있다. |
| 해외 시민 | 해외 시민인 구직자. |

### 필로니아 시민의 세부 조건

| 세부 조건 | 해당 구직자 |
| --- | --- |
| 오르테시아 기사단 소속 또는 기사단 발령 | 오르테시아 기사단에 소속되어 있거나 이 기사단의 발령으로 온 구직자. 개척 초기에는 기사단에서 파견된 구직자들이 찾아온다. |
| 오르테시아 지부의 특정 공회 소속 | 특정 공회의 오르테시아 지부에 소속된 구직자. |
| 타 지역 기사단 또는 공회 소속 | 다른 지역의 기사단이나 공회에 소속된 구직자. |

## 제출 서류

- **이력서:** 모든 구직자가 기본으로 제출한다. NPC의 능력치(스탯)와 특기 등을 나타내며, 심사 이후 [인력 배정](인력%20배정과%20마을%20발전.md) 단계에서도 쓰인다.
- **신분증:** 본인의 신분을 증명한다. 국가마다 양식이 다르다.
- **증빙서류:** 구직 자격과 신청한 작업 종류에 따라 요구되는 서류가 달라진다.

### 조사단 자격의 필요 서류

조사단 자격을 가진 구직자는 다음 세 가지 서류를 제출한다.

| 서류 | 내용 |
| --- | --- |
| 이력서 | 모든 구직자의 공통 서류 |
| 필로니아 공화국 신분증 | 필로니아 공회정에서 정식으로 파견된 조사단원을 다루므로, 현재 조사단 자격 심사에는 필로니아 공화국의 신분증만 등장한다. |
| 조사단원증 | 엠브릴 조사단의 일원임을 증명한다. |

## 접수 절차

1. **신청 확인:** NPC가 원하는 일의 분야와 작업 종류를 확인한다.
2. **제출 서류 확인:** 이력서와 신분증, 해당 신청에 필요한 증빙서류가 모두 제출되었는지 확인한다.
3. **서류 검사:** 각 서류의 내용을 면밀히 살펴 누락된 항목이 없는지 검사한다.
4. **정보 대조:** 이력서, 신분증, 증빙서류 사이에 서로 일치하지 않는 정보가 있는지 확인한다.
5. **처리 결정:** 검사 결과에 따라 신청을 승인해 접수하거나 거부한다.

## 처리 결과

| 결과 | 처리 방식 |
| --- | --- |
| 승인 | 제출 서류에 누락이나 불일치가 없으면 신청을 승인하고 접수한다. |
| 거부 | 누락되거나 불일치하는 부분이 있으면 해당 사유를 라벨로 표시하고 거부 도장을 찍은 뒤 서류를 신청인에게 돌려준다. |

## 난이도의 성장

사업체가 늘어나고 더 높은 수준의 일꾼들이 찾아오기 시작하면 구직 심사의 난이도도 함께 오른다.

- 다양한 구직 자격을 가진 구직자가 찾아온다.
- 특수한 스킬이나 자격증을 증명해야 하는 신청이 늘어난다.
- 플레이어는 더 복잡해진 신분과 자격 조건을 정확히 판정해야 한다.

어려운 심사를 통과시켜 확보한 고급 인력은 다시 인력 배정 단계에서 높은 노동력이나 전문 능력을 요구하는 마을 발전 의뢰에 투입된다. 이 순환은 [게임 개요의 핵심 성장 순환](게임%20개요.md#핵심-성장-순환)에서 다룬다.

## 미정 사항

- 조사단 자격을 제외한 나머지 자격별 필요 서류 구성
- 각 서류의 구체적인 기재 항목과 양식, 심사 항목과 퍼즐 요소
- 조사단 자격을 제외한 각 자격과 필로니아 시민 세부 조건별 난이도, 그 상대적인 순서
- 자격별 구체적인 등장 시점과 조건 (개척 초기의 기사단 파견 구직자는 확정)
