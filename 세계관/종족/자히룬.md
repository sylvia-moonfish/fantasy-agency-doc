# 자히룬

**자히룬**(`Zāhirūn`, `زاهرون`)은 몸 전체가 사암이나 규암으로 이루어진 [인간](지성체의%20분류.md#인간) 종족이다. 케메티아 대륙 북동부의 광활한 사막에 자리한 [자하라힘](../케메티아%20대륙.md#자하라힘)을 터전으로 삼아 살아간다.

| 항목 | 내용 |
| --- | --- |
| 분류 | 인간 |
| 신체 | 몸 전체가 사암이나 규암으로 이루어짐 |
| 거주지 | [자하라힘](../케메티아%20대륙.md#자하라힘)의 사막 |
| 작명 모티브 | 아랍어 |

## 신체와 거주지

자히룬의 몸 전체는 사암이나 규암으로 이루어져 있다. 이들은 자하라힘의 광활한 사막을 터전으로 삼아 살아간다.

필로니아에서는 북동부의 교역 관문인 [카르세나 회랑](../필로니아의%20지역.md#카르세나-회랑)에서 상인과 노동자로 드나드는 자히룬을 볼 수 있다.

## 명칭

`자히룬`은 아랍어로 빛나고 색이 선명한 존재를 뜻하는 `Zāhir`(`زاهر`)에 지성체 집단을 나타내는 복수형 어미 `-ūn`(`-ون`)을 결합한 `Zāhirūn`(`زاهرون`)에서 유래했으며, `빛나는 존재들`이라는 의미를 지닌다.

이 이름과 [자하라힘](../케메티아%20대륙.md#자하라힘)의 국명에 쓰인 `자하라`는 모두 `빛나다`, `반짝이다`, `꽃피다`라는 의미의 아랍어 어근 `Z-H-R`(`ز-ه-ر`)을 공유한다.

자히룬과 관련된 명칭, 호칭, 인명은 아랍어 계열의 어휘와 어감을 모티브로 삼아 작명한다.
