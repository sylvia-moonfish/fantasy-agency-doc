# 케흐랴이넨

**케흐랴이넨**(`Kehrjäinen`)은 쏙독새를 모티브로 한 수인 [인간](지성체의%20분류.md#인간) 종족이다. 케메티아 대륙의 [북부의 삼림 지대](../케메티아%20대륙.md#북부의-삼림-지대)에 사는 토착 종족으로, 온대 혼합림과 타이가 지역에 넓게 퍼져 산다. 다른 종족들은 이들을 줄여서 **케흐리**라고 부른다.

| 항목 | 내용 |
| --- | --- |
| 분류 | 인간 |
| 모티브 | 쏙독새 (수인) |
| 거주지 | [북부의 삼림 지대](../케메티아%20대륙.md#북부의-삼림-지대)의 온대 혼합림과 타이가 |
| 다른 종족이 부르는 이름 | 케흐리 |
| 작명 모티브 | 핀란드·에스토니아계 발트핀어군 |

## 거주지

케흐랴이넨은 동부 대초원의 북쪽에서 필로니아 공화국의 북쪽을 지나 티르 나 브레아의 동쪽까지 이어지는 [북부의 삼림 지대](../케메티아%20대륙.md#북부의-삼림-지대)에 산다. 이 지대 가운데 침엽수와 활엽수가 섞여 자라는 온대 혼합림과, 더 북쪽의 냉대 침엽수림인 타이가에 넓게 퍼져 있다.

필로니아에서는 북동부의 [카르세나 회랑](../필로니아의%20지역.md#카르세나-회랑)을 나서면 이들이 사는 온대 혼합림에 닿는다.

## 명칭

`케흐랴이넨`(`Kehrjäinen`)이라는 종족명은 쏙독새를 뜻하는 핀란드어 `kehrääjä`에 인물·종족 이름에 쓰이는 어미 `-inen`을 붙이고 어감을 다듬어 만든 이름이다. `kehrääjä`는 "실 잣는 이"라는 뜻으로, 쏙독새의 울음소리가 물레 돌리는 소리와 닮았다는 데서 붙은 이름이다.

다른 종족들은 이 이름을 줄여 `케흐리`라고 부른다.

케흐랴이넨과 관련된 이름, 호칭, 고유 명칭은 핀란드·에스토니아계 발트핀어군의 어휘와 어감을 모티브로 삼아 작명한다.

## 미정 사항

- 신체, 생태, 수명, 번식, 사회와 문화 등 상세 설정
